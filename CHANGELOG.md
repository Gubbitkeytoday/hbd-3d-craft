## [1.0.0] - 2026-08-20

### Added
- **Procedural 3D Cake Generator**: Custom Three.js geometries with hand-piped cream beads, customizable tiers, and realistic fruit meshes.
- **Web Audio API Mic Candle Blowing**: Real-time frequency analysis to extinguish candles via microphone.
- **3D Wax-Sealed Envelope Gate**: Interactive letter unfolding animation powered by Anime.js.
- **Stateless URL Payload Engine**: Zero-database card encoding into URL hash fragments.
- **9 Glassmorphic Themes**: Dynamic HSL color token system with ambient WebGL lighting.
- **3-Language Localization**: English, Thai (ภาษาไทย), and Japanese (日本語).
